Proposed milestones · expand for acceptance gates

M0Pin the corpus and connect cargo test

Gate: enumerate all 226 cases; prove the harness catches altered results. Test Markdown separately against reference cleaned HTML. The TypeScript bridge is already validated; the native runner is next.

M1Prove the mutable DOM and sanitization

Gate: selector, template, clone, namespace, table, and scoped-query probes pass. Preserve static shadow/streaming content and pass poisoned-input tests with cleanup disabled.

M2Port Markdown conversion in isolation

Gate: exact non-math conversion parity and applicable Markdown security regressions. Evaluate htmd in a bounded spike; explicitly port Defuddle’s 20 custom rules.

M3Port generic selection, cleanup, and retries

Gate: declared prose, layout, hidden-content, and metadata subsets match; retry thresholds and sanitized fallbacks have focused tests.

M4Complete rich content and full math

Gate: all 209 generic cases and all four HTML goldens pass, with any approved parser deviations reported separately. Cover footnotes, code, images, tables, SVG, and both math conversion directions.

M5Port local site adapters and replies

Gate: 226/226 Markdown and metadata goldens; oracle HTML, word counts, and extractor types pass or have individually recorded parser deviations. Port relevant inline adapter/security tests as well.

M6Close regressions, fuzz, and benchmark

Gate: no unclassified in-scope failures or security exceptions. Reproducible native tests, preserved attribution, and comparable end-to-end latency/memory measurements.
